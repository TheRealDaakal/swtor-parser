SWTOR's combat log never reports your actual Alacrity stat, so this has to be typed in from your character sheet. Used to scale DoT/HoT countdown durations to match how fast they actually tick for you -- e.g. Corrosive Dart ticks 6 times regardless of Alacrity, so more Alacrity means those ticks (and the debuff itself) finish sooner.

Merge multiple people's logs

For filling visibility gaps: pick two or more raiders' saved .txt logs from the SAME fight and this combines them into one encounter, keeping every event either log recorded (duplicates across the overlapping files are detected and only counted once). Not needed for normal use -- your own log already records the whole group's actions, not just yours -- only useful when someone was out of your log's visibility range for part of the fight and a teammate's log covers what yours missed.

Picking a SINGLE file here just re-imports that one log as one big combined encounter (the whole file, not split into individual pulls) -- Parsely upload works for that case, but not when multiple files are actually merged, since events from different files don't share one real line range to point Parsely at.

Import an old session log

For backfilling History: pick ONE of your own saved .txt logs (a previous night, or a session you weren't running the app for) and this replays it exactly like the live tailer would have -- splitting it into its real individual pulls, with boss/phase recognition applied to each one. Trivial slivers (looting, a stray pull that never did damage) are skipped automatically. Each real pull is added to History as its own entry, Parsely upload included. Re-importing the same file is harmless -- pulls already in History are detected and skipped instead of duplicated.
